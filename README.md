### 🚀 About This Repository

This repository hosts the static source files for my personal engineering & leadership portfolio site, automatically served via **GitHub Pages**. 

It showcases my experience in **Data Analytics, Data Engineering, Revenue Cycle Management (RCM), and Growth Operations Strategy**.

### 🛠️ Architecture & Tech Stack

- **Frontend:** Vanilla HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, Custom Keyframes)
- **Interactivity:** Vanilla JavaScript (Canvas Particle Node System, Auto-Typing Effect, Hardware-Accelerated 60fps Image Motion)
- **Deployment:** GitHub Pages (Static Hosting)
